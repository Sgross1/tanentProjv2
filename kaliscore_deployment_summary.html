KaLiScore - קל לשכור

מפרט טכני וסיכום פרויקט פולסטאק

הקונספט: מערכת לדירוג כלכלי אוטומטי של שוכרים המבוססת על אלגוריתם חכם וניתוח מסמכים (OCR).

הערך המוסף: חסכון בזמן למשכירים, ייעול תהליך המיון והצגת "תעודת זהות פיננסית" אמינה לשוכרים.

ניתוח טכנולוגי וארכיטקטורה
1. ארכיטקטורת Fullstack הפרדה מלאה בין Angular 19 (לקוח), .NET 9 (שרת) ו-SQLite (נתונים).
יתרונות: Scalability (שדרוג משאבים בנפרד) ואבטחה מרכזית דרך API מאובטח (JWT).
2. צד השרת (Clean Arch) חלוקה לשכבות Presentation, Logic, Infrastructure.
דוגמת OCR: הקונטרולר מקבל קובץ, הסרוויס מנהל את הניתוח, והתשתית פונה ל-Azure.
יתרון: Decoupling המאפשר תחזוקה קלה והחלפת טכנולוגיות ללא שינוי הלוגיקה העסקית.
3. צד הלקוח (SPA & UX) מערכת SPA המבוססת קומפוננטות וניתוב (Router) ללא טעינת דפים.
ביצועים: שימוש ב**אסינכרוניות** (Observables) לתגובתיות מקסימלית.
אלמנט ויזואלי: קומפוננטת קוביה תלת-ממדית אינטראקטיבית לניהול State ויזואלי.
4. ניהול נתונים (ORM) עבודה בשיטת Code First עם **Entity Framework Core**.
שימוש ב-Entities ו-Migrations לסנכרון הסכמה.
יתרון: ניהול נתונים רלציוני גמיש ומהיר המותאם בצורה אופטימלית לשרת ה-AWS.
5. פריסה (Cloud & Docker) אירוח ב-**AWS** על שרת **EC2** עם אחסון **EBS**.
אורקסטרציה דרך **Docker Compose** בתוך Containers מבודדים.
יתרון: Environment Consistency מלא בין הפיתוח המקומי לסביבת הייצור החיה.
